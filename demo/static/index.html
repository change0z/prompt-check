Guardrails + analytics for ERP assistants

Put an AI assistant inside an ERP and two problems show up fast. Some prompts should never reach it: injections, jailbreaks, grabs for credentials, or data outside the user's role. And once it is live, nobody can see what people actually ask it.

One small classifier can handle both. It tags every prompt with a verdict, an ERP area and an intent in milliseconds: before the assistant sees it, to stop what shouldn't get through, and after the session, to show what is being used and what is being tried.

How it works

One small model, one pass, every message. It returns labels, never text, so it can't be talked into saying anything. The same labels, stored per prompt, become the analytics: the heatmap in the playground is that view.
