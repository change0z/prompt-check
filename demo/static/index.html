About

What you are testing

Our ERP has a built-in AI assistant that answers questions about everyday work, such as stock levels, invoices, purchase orders and staff records. Before a question reaches the assistant, a small, fast classifier checks it. This page tests that classifier.

Why you get a role

The ERP covers HR, finance, inventory, purchasing, sales and system administration, and each role sees only its own area. The same question can be fine from one role and snooping from another: salaries are normal for an HR admin and suspicious from a warehouse operator. The models see your role along with your prompt.

The base model

  • GLiNER2.5-Decide by Fastino, a 340 million parameter classification model. It picks labels in one pass and does not generate text.
  • Built on Microsoft's DeBERTa-v3-large encoder.
  • Licence: Apache 2.0 for GLiNER2.5-Decide, MIT for DeBERTa-v3.
  • Source: Hugging Face, GitHub and the GLiNER2 paper.

The fine-tuned model

  • The same base model plus a small LoRA adapter, about 30 MB, that we trained. The base weights are unchanged.
  • Trained on about 500 synthetic ERP prompts written for this project, with no real customer, employee or company data.
  • On a separate hand-written test set, it raised fewer false alarms and labelled the ERP area and intent much more accurately than the base model.

How scoring works

After both models answer, you vote on whether the prompt should have been blocked. A model scores when it agrees with you. Prompts without a vote are stored but not scored. Votes are opinions, so we review them before using any prompt for training.

What we collect

We collect only the prompt you type and the feedback you give. With each prompt we store:

  • the prompt text and your vote,
  • the role you were given and both models' answers,
  • the time it was submitted.

We do not ask for your name or email, set no cookies, and do not store your IP address with your prompt. The server and our hosting provider keep standard request logs for a limited time. Please do not paste real customer, employee or credential data. We use the prompts only to evaluate and retrain the classifier.

An internal experiment. The classifier is a prototype and does not protect any live system from this page.
