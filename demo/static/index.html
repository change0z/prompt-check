About this demo

What is under the hood, where it came from, and what we keep.

What you are playing against

Our ERP has a built-in AI assistant that answers questions about everyday work: stock levels, invoices, purchase orders, staff records and so on. Before a question reaches the assistant, a small and fast classifier checks it. This page lets you test that classifier.

For each prompt it picks a category, the ERP area and the intent. All three are explained in the label index above.

Why you get a role

The ERP covers HR, finance, inventory, purchasing, sales and system administration, and each role can see only its own area. The same question can be fine from one role and snooping from another. Asking for salaries is normal for an HR admin and suspicious from a warehouse operator. The models see your role alongside your prompt.

The base model

  • GLiNER2.5-Decide by Fastino, a 340 million parameter classification model. It picks labels in a single pass and does not generate text.
  • Built on Microsoft's DeBERTa-v3-large encoder.
  • Licence: Apache 2.0 for GLiNER2.5-Decide, MIT for DeBERTa-v3.
  • Source: Hugging Face, GitHub, and the GLiNER2 paper.

Our fine-tuned version

  • The same base model plus a small LoRA adapter of about 30 MB that we trained. The base weights are unchanged.
  • Trained on about 500 synthetic ERP prompts written for this project. It contains no real customer, employee or company data.
  • On a separate hand-written test set, it raised fewer false alarms and labelled the ERP area and intent far more accurately than the base model.

How scoring works

After both models answer, you vote on whether the prompt should have been blocked. A model scores when it agrees with you, and wins the round if it is the only one that does. Rounds without a vote are stored but not scored. Votes are opinions, so we review them before using any prompt for training.

What we collect

We collect only the prompt you type and the feedback you give. With each prompt we store:

  • the prompt text and your vote,
  • the role you were given and both models' answers,
  • the time it was submitted.

We do not ask for your name or email, set no cookies, and do not store your IP address with your prompt. The server and our hosting provider keep standard request logs for a limited time. Please do not paste real customer, employee or credential data. We use the prompts only to evaluate and retrain the classifier.

An internal experiment. The classifier is a prototype and does not protect any live system from this page.
